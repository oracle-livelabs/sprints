# How do I test sprint validation?
Duration: 5 minutes

## Answer

This disposable sprint verifies that the sprint validation workflow runs on pull requests, pushes, and manual workflow runs.

1. Open a pull request with this valid sprint.
2. Confirm the sprint validation and image validation checks run.
3. Introduce one deliberate validation issue at a time.
